## 1. 概述

### 1.1 项目背景

V0.1版本聚焦于**岗位相关自学课程 + 课程考试**，取消培训模块。学员通过自主学习完成岗位课程，并参加课程关联的考试获取认证。

### 1.2 V0.1范围

| 模块 | 功能 | 说明 |
|------|------|------|
| 课件管理 | 课件上传、分类管理 | 视频/图文/文档/3D课件资源 |
| 课程管理 | 课程分类、创建、发布、岗位绑定 | 关联考试 |
| 考试管理 | 试题管理、试卷管理、考试配置 | 自动评分 |
| 任务管理 | 课程任务创建 | 启动时自动通知 |
| 学员学习 | 课程学习、考试 | 顺序学习+自动评分 |
| 基础管理 | 组织架构、岗位管理 | 基础数据维护 |
| 系统管理 | 用户管理 | 用户维护 |

**本次版本不包含：** 培训管理、报名审批、签到管理、内训管理、晋升管理等模块。

### 1.3 系统角色

| 角色 | 说明 |
|------|------|
| **厂端管理员** | 课件管理、课程管理、考试管理、任务管理、基础管理、系统管理 |
| **学员** | 我的任务、课程学习、参加考试 |

## 5. 业务规则

### 5.1 课程学习规则

1. 课程按章节顺序学习，需完成当前章节后才能进入下一章节
2. 若章节设置了章节考试，需通过考试后才能进入下一章节
3. 完成课程所有章节后，获得参加课程关联考试的资格

### 5.2 考试规则

1. 课程完成后自动获得考试资格
2. 考试成绩达到合格分数为"已通过"
3. 考试可设置限考次数
4. 学员在考试开放期间参加考试，提交后系统自动评分

### 5.3 任务规则

1. 任务开始时系统自动向学员发送通知
2. 任务有开始时间和截止时间
3. 学员仅在任务开始后获取任务

#### 6.2.1 模块结构

|----------|----------|------|

| 课程管理 | 课程分类管理 | 课程分类维护 |
| | 课程列表 | 课程创建、编辑、发布、下架 |
| | 课程详情 | 章节管理、小节管理 |
| | 岗位课程绑定 | 课程与岗位等级绑定 |

| | 岗位管理 | 岗位类型和等级维护 |
| 系统管理 | 用户管理 | 用户信息维护 |

#### 6.2.2 功能说明

**课件管理**

- 厂端管理员上传视频/图文/文档/3D课件
- 课件分类管理，建立课件归类体系
- 支持启用/禁用课件

**课程管理**

- 课程分类管理：建立课程分类体系
- 课程维护：创建、编辑、发布、下架课程
- 章节管理：在课程下添加、编辑、删除章节
- 小节管理：在章节下添加、编辑、删除小节，引用课件
- 关联考试：选择已创建的考试关联到课程
- 岗位课程绑定：将课程绑定到指定岗位等级

**考试管理**

- 试题管理：维护考试题库，支持单选/多选/判断题
- 试卷管理：引用外部试卷或创建试卷
- 考试管理：配置考试属性（考试名称、合格分数、考试时长、限考次数等）

**任务管理**

- 创建课程任务，设置任务名称、开始时间、截止时间
- 编辑、关闭任务
- 任务开始时自动通知学员

**基础管理**

- 组织架构管理：维护组织机构（厂端、门店）
- 岗位管理：维护岗位类型和等级

**系统管理**

- 用户管理：维护用户信息、用户类型

### 6.3 学员端

#### 6.3.1 模块结构

#### 6.3.2 功能说明

**我的任务**

- 学员查看推送的课程任务和考试任务
- 课程任务：显示课程名称、开始时间、截止时间、完成状态
- 考试任务：显示考试名称、开始时间、截止时间、通过状态
- 点击任务进入课程学习或考试答题

**课程学习**

- 课程列表：展示被推送的课程，显示学习状态（未学习/学习中/已完成）

- 按章节顺序学习，完成当前章节后才能进入下一章节

**我的考试**

- 考试列表：查看可参加的考试及历史成绩
- 考试答题：参加课程关联的考试
- 系统自动评分，返回成绩

**个人中心**

- 查看和修改个人信息
